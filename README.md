# 🏙️ 20 сайтов для заведений Челябинска

Коллекция из 20 современных, адаптивных и полностью автономных сайтов (лендингов) для реальных локальных заведений и малого бизнеса г. Челябинска, у которых не было собственных веб-сайтов (присутствовали только в 2ГИС, Яндекс.Картах или сообществах ВКонтакте).

Все сайты оформлены в индивидуальном стиле, адаптированы под мобильные устройства и содержат актуальную городскую информацию: адреса, ориентиры, телефоны, часы работы, прайс-листы, преимущества, отзывы и интерактивные формы онлайн-записи и бронирования.

## 🚀 Как просматривать сайты

### Вариант 1. Открыть единый каталог (Portal Showcase)
Откройте в любом веб-браузере файл:
`C:\Users\root\.gemini\antigravity\scratch\chelyabinsk-sites\index.html`

В каталоге доступны:
- Живой поиск по названию заведения, улице или услуге;
- Фильтрация по категориям (Еда/кофе, Красота, Авто, Ремесло, Питомцы, Йога, Цветы, Дети);
- Быстрый просмотр любого сайта в интерактивном модальном окне (iframe) прямо из каталога;
- Прямой переход на сайт любого из 20 заведений.

### Вариант 2. Запуск локального сервера
В папке проекта выполните:
```bash
cd C:\Users\root\.gemini\antigravity\scratch\chelyabinsk-sites
python -m http.server 8080
```
И откройте в браузере: `http://localhost:8080`
